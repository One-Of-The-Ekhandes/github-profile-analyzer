### **GitHub Profile Analyzer**  
🔍 A Python tool that fetches and analyzes GitHub user data, displaying profile details and repository statistics, including a visualization of languages used across repositories.  

## 📌 Features  
✅ Fetches **GitHub profile details** (name, followers, public repos).  
✅ Retrieves **repository data** for analysis.  
✅ Visualizes **programming languages** used in repositories.  
✅ Simple and **easy-to-use CLI** interface.  

## 🛠️ Installation  
1. **Clone the repository**  
   ```bash
   git clone https://github.com/yourusername/github-profile-analyzer.git
   cd github-profile-analyzer
   ```  
2. **Install dependencies**  
   ```bash
   pip install requests matplotlib pandas
   ```  
3. **Run the script**  
   ```bash
   python github_analyzer.py
   ```  

## 🚀 Usage  
- Enter any **GitHub username** when prompted.  
- The script will fetch and display the user's profile details.  
- A **bar chart** will be generated, showing the languages used across repositories.
